# Project context: GitLab comment threads redesign

The recording is a public GitLab UX team call ("UX Group Feedback: Threaded discussions", GitLab Unfiltered on YouTube). A product designer screen-shares a visual redesign of the threaded discussion and comment UI that appears on GitLab issues and merge requests, and teammates react and give feedback.

Treat the presenting designer as the delivery team and the other participants' spoken reactions, requests, concerns, and questions as the feedback to triage. The product is GitLab's web UI, specifically discussion threads: comments, replies, resolving threads, avatars, timestamps, and related controls.

The redesign is a work-in-progress mockup, so feedback about the mockup itself is in scope. General conversation, meeting logistics, and the presenter's own explanation of the design are not change requests.
